# 🧠 Machine Learning Repository  

Este repositorio contiene implementaciones y experimentos con **modelos de aprendizaje supervisado y no supervisado**.  
El objetivo es crear un espacio de práctica y documentación para mejorar habilidades en **ciencia de datos, modelado y evaluación de algoritmos**.  

---

## 🚀 Contenido  

### 📂 Estructura del repositorio
- `data/` → Conjuntos de datos de ejemplo para entrenar y probar modelos.  
- `notebooks/` → Notebooks en Jupyter con implementaciones paso a paso.  
- `scripts/` → Código modular en Python para entrenamiento, evaluación y visualización.  
- `models/` → Modelos entrenados y archivos relacionados.  
- `docs/` → Documentación y recursos adicionales.  

### 📊 Modelos supervisados
- Regresión Lineal y Logística  
- Árboles de Decisión y Random Forest  
- Support Vector Machines (SVM)  
- Redes Neuronales Básicas  
- Gradient Boosting (XGBoost, LightGBM, CatBoost)  

### 🌀 Modelos no supervisados
- K-Means  
- Clustering Jerárquico  
- DBSCAN  
- Análisis de Componentes Principales (PCA)  
- t-SNE y UMAP para reducción de dimensionalidad
